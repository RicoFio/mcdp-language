# Monotone Co-Design Problem Language (MCDPL) Tooling

Syntax highlighting, snippets, completion, and recommendations for MCDPL files in Visual Studio Code.

Enhance your MCDPL's readability and speed-up your design speed:

- Syntax highlighting for `.mcdp`, `.mcdp_interface`, `.mcdp_poset`, and `.mcdp_template` files.
- Semantic colors for document openers, provided variables, required variables, instance bindings, backtick model names, backtick poset names, and resource declarations.
- Recommendations while typing common MCDPL forms, including document templates, statements, primitive posets, model names, resource paths, and instance-scoped port expressions.

## Supported Files

- `.mcdp`
- `.mcdp_interface`
- `.mcdp_poset`
- `.mcdp_template`

## Usage

Open an MCDPL file in Visual Studio Code. Highlighting and recommendations are enabled automatically for supported file extensions.
